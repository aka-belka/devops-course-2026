## 1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?

В Git ветка это просто указатель на коммит.
Создание ветки мгновенно, не требует копирования файлов.
В SVN ветка это копирование директории на сервере.
Это медленно и требует места, поэтому ветвление используется редко.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет, так как SVN это централизованная система.
Все коммиты идут на центральный сервер, поэтому нужна сеть.
В Git коммиты делаются локально, а потом отправляются на сервер (push).

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

- Legacy-проекты (госсектор, банки), где уже используется SVN
- Простые проекты с линейной историей и без ветвления
- Команды, которые не хотят переучиваться
- Когда нужен строгий централизованный контроль доступа
